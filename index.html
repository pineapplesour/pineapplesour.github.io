Core Philosophy

How We Resolve Agent Drift

Single LLM self-critique leads to hallucination cascades. Reliable long-horizon execution requires structural role-separation and blind reviewer convergence.

1
🧠

Task Solver

Generates complex scripts or actions within a strictly sandboxed, metadata-frozen environment.

2
👥

Independent Evals

Two separate reviewers (Eval A & B) inspect the output blind, with no access to each other’s reasoning paths.

3
🥬

Overlap Extract

The Composer extracts only the overlapping criticisms, ignoring individual model noise and random drift.

4
🛡️

Orchestrator Gate

Grades consensus, logs paths in the state ledger, and promotes candidates only if independent agreement is reached.
